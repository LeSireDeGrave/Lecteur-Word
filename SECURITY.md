# Sécurité et confidentialité / Security and privacy

## Français

Signaler une vulnérabilité en privé via [GitHub Security](https://github.com/LeSireDeGrave/Lecteur-Word/security). Indiquer la version, le SHA de compilation, les étapes et un témoin synthétique. Pour les anomalies ordinaires et les suggestions, utiliser les formulaires d’[Issues](https://github.com/LeSireDeGrave/Lecteur-Word/issues/new/choose).

Les documents sont ouverts en lecture seule. Les macros et objets OLE ne sont pas exécutés et les ressources externes référencées par les DOCX ne sont pas chargées. Les préférences et le cache d’extensions restent locaux. Le catalogue utilise HTTPS quand l’utilisateur le configure et l’actualise. Les liens de support ouvrent GitHub sur demande. L’application n’envoie pas automatiquement de document ou de rapport.

## English

Use [GitHub Security](https://github.com/LeSireDeGrave/Lecteur-Word/security) to report vulnerabilities privately. Include the version, build SHA, reproduction steps and a synthetic fixture. Use [Issues](https://github.com/LeSireDeGrave/Lecteur-Word/issues/new/choose) for ordinary bugs and suggestions.

Documents are opened read-only. The reader neither runs macros or OLE objects nor loads external resources referenced by a DOCX. Preferences and extension caches are stored locally. Catalogue requests use HTTPS when configured and refreshed. Support links open GitHub on request. Documents and reports are never sent automatically.
