# Présenter Lecteur Word

## Français

Lecteur Word est un lecteur DOCX autonome et libre pour Linux. Il propose 20 langues d’interface, des thèmes personnalisables et des extensions communautaires. Ses développements originaux sont sous licence MIT.

**DOCX → PDF / ODT / EPUB 3 / NOVA**

- **PDF** pour partager et imprimer.
- **ODT** pour modifier librement.
- **EPUB 3** pour lire et publier.
- **NOVA** pour écrire dans OpusNova, avec le schéma v27.

Le lecteur ouvre les fichiers DOCX en lecture seule. L’export compatible indique les adaptations du document avant la conversion. [Guide utilisateur](guide-utilisateur.fr.md)

## English

Lecteur Word is a standalone, open-source DOCX reader for Linux. It offers 20 interface languages, customizable themes, and community extensions. Its original work is licensed under MIT.

**DOCX → PDF / ODT / EPUB 3 / NOVA**

- **PDF** to share and print.
- **ODT** to edit freely.
- **EPUB 3** to read and publish.
- **NOVA** to write in OpusNova, using schema v27.

The reader opens DOCX files in read-only mode. Compatible export shows adaptations before conversion. [User guide](user-guide.en.md)
